# 교육철학

> ⚠️ core/ 운영자 전용 문서. 내용 작성·수정은 운영자 사전 승인 하에만 진행한다.

## 제1원칙 — "모든 문제는 풀 수 있다"
- 모든 교육철학의 출발점.

## 질답(Q&A) 원칙 — 학생 풀이를 완성시킨다
수업의 원형은 수학 단과 수업이다. (관리팀에는 수학을 직접 가르치지 않는 수업도 있지만, 철학의 뿌리는 여기에 있다.)

기존 방식과의 차이: 보통 학원·과외는 질답 문항을 그냥 풀어주고 끝낸다.

**진행 순서:**
1. 학생의 풀이를 먼저 읽는다. 질답 문항을 받으면 반사적으로 묻는다 — **"그래서 어떻게 풀려고 했어?"**
2. 풀이가 멈춘 지점에서 소통하며, 학생 자신의 풀이를 끝까지 완성시킨다. (선(先) 질답)
3. 그 다음 다른 풀이·더 좋은 풀이들을 보여주고, 풀이 간의 차이점과 장단점을 해설한다. (특히 킬러문항)

**노리는 효과:** 학생이 "아, 내가 좀 더 고민했더라면 풀 수 있었겠다"라고 생각하게 유도하는 것이 포인트다. — 제1원칙("모든 문제는 풀 수 있다")을 학생이 체감하게 만드는 장치.

**적용 범위:** 주로 상위권 학생 수업에 적용해 왔다. 이유: 하위권 학생의 질답 문항은 대부분 풀이가 단순해서 복수의 풀이가 존재하지 않기 때문.

**운영자 주석(해석):** 실제로는 대부분의 풀이가 겹친다 — 연산 순서나 조건 적용 순서만 다른 경우가 많아, 내용상 기존 해설강의와 크게 다르지 않다. 그러나 "좀 더 고민하면 풀 수 있었다"는 경험을 학생에게 만들어 준다는 점이 결정적 차이다.
→ 이 방식의 사업적 가치는 [사업전략.md](사업전략.md) 참조.

## 가정 교육방식 — 철학의 원천
**성장 배경(사실):** 운영자는 어릴 때 공부를 좋아하지도, 하지도 않던 학생이었다. 첫 동기는 '닌텐도' — 엄마가 교내 수학경시대회 수상(은상/금상)을 조건으로 걸었다. 이후 KMO 수상자 수준까지 성장.

집안 교육철학의 2대 특징:

### ① 상/벌의 엄격한 규율 + 물질적 결핍 교육
- 의/식/주는 최선으로 제공하되, 그 외 모든 것은 부모가 정한 대가를 치러야 얻는 구조. (예: 엄마 종아리 안마 1000번 → 용돈 1000원)
- 보상 기준은 예외 없이 집행: "단원평가 100점이면 만원"에서 99점을 받으면 아무리 안타까워하고 슬퍼해도 절대 예외 없음. **약속은 약속이다.**
- 상의 대가는 항상 성취하기 어려운 목표였다.

### ② 점수가 아니라 '태도'를 평가
- 공부를 안 하거나 낮은 점수를 받아도 문책하지 않았다. "밤새 공부해라", "왜 노력하지 않았냐" 같은 문책도 없음.
- 유일한 피드백: **"이번 시험으로 무엇을 느꼈는지, 아쉬운 부분과 문제점을 스스로에게서 찾았는지."** 스스로에게서 찾았다면 그것으로 OK. 점수 압박·문책 없음.
- 결과: 자식들이 성적에 대한 부모와의 소통에 거부감이 없었다 (평화로웠다).

→ 이 두 축이 관리팀 운영의 원형이다. 적용 방법은 [미션설계철학.md](미션설계철학.md) 참조.
