# 미션 설계 매뉴얼

> 후임자 열람 가능 문서. 미션 설계의 실행 절차를 담는다.
> 설계 '철학'은 core/미션설계철학.md (운영자 전용)에 있다.

## 주단위 계획 실행법
1. **계획 작성:** 학생의 스케줄(학원·가족 일정·친구 약속 등)을 전부 파악한 뒤, **일요일 없이 월~토** 기준으로 계획을 짠다. 학생이 책임질 수 있는 계획임을 학생에게 신신당부한다.
2. **미완 분량 처리:** 전날 과제를 다 못 했어도 다음날로 밀지 않는다 — 당일 과제는 독립적으로 진행하고, 미완 분량은 **일요일에 몰아서 마무리**한다. (매일 다 하면 일요일은 노는 날 = 보상)
3. **변경·수정 불가:** 주단위 계획은 변경·수정이 없다. 질병·피치 못할 사정만 **학부모 확인을 받고** 감안 가능.
4. **첫 주 과제량:** 학생이 할 수 있어 보이는 최대 분량 **+1할** — 정보처리 능력 테스트 목적.
5. **예외를 봐준 경우:** 타 학생에게 절대 비밀로 한다 (기강 보호). 예외는 거의 일어나서는 안 된다.

## 목표 설정 대화 (신규 학생·상담)
1. 무조건 가능하다고 말하지 않는다 — 긍정적이되 실제로 가능해 보이는 선에서.
2. 선고지: **"실력이 높을수록 스스로 잘하지 못한다고 생각한다(자기에게 요구하는 완성도가 높아져서). 그래서 하면 할수록 목표치가 조금씩 낮아진다."**
3. 학생이 끄덕이거나 긍정하면 → 현실 가능거리의 **최댓값** 제시: "그래도 한양대 정도는 목표로 잡아야 하지 않겠어? 지금 성적에서 ~하면 한양대는 가겠다."
4. 비현실 질문(최하위권의 "만점 가능?"): 가능성을 단정하지 않는다 — "그건 나도 대답할 수 없지, 너도 모르는 걸 누가 알겠어. 하지만 계속 이런 식으로 공부하면 지방대 간다는 건 알겠어." (현재 경로의 확실한 결과만 단정. 강한 화법은 예외적으로만)
5. 트랙레코드가 없으면(신규 학생·후임 선생) **성공한 케이스들을 놓고 이야기한다.**

## 보상 협상 시 고지
- 계약 초에 학부모에게 규칙을 설명한다: **"미달이면 절대로 주시면 안 됩니다 — 미달 상태에서 주시면 학생의 지속성이 확연하게 떨어집니다. 대신 목표는 어렵게, 보상은 화끈하게."**
- 학부모가 규칙을 어기고 미달에 보상을 줘도 **지적하지 않는다** (그 가정의 교육 방식을 인정, 못 본 척). 시간차를 두고 다음 보상안·계획 수립으로 넘어간다.
